# DME Component Libraries Examples

This repository showcases example applications for DME Component Libraries, a commercial product from AGI, an Ansys Company.

## What is DME Component Libraries?

DME Component Libraries provides powerful class libraries for either .NET or Java to help developers working on land, sea, air, and space systems solve today's most difficult engineering and mission challenges with high fidelity. Whether you are building a small utility to process some proprietary data, a world-class desktop aerospace software application, a multi-user web application, or a piece of a service-oriented architecture (SOA), DME Component Libraries can help.

More information about DME Component Libraries is available from [AGI's website](https://www.agi.com).

The DME Component Libraries documentation (available for [.NET](https://help.agi.com/AGIComponents/html/Welcome.htm) and [Java](https://help.agi.com/AGIComponentsJava/html/Welcome.htm)) includes a Programmer's Guide as well as full API documentation for the complete set of capabilities provided by DME Component Libraries.

Full system requirements for DME Component Libraries are listed in the documentation ([.NET](https://help.agi.com/AGIComponents/html/SystemRequirements.htm) / [Java](https://help.agi.com/AGIComponentsJava/html/SystemRequirements.htm)).

## What are these example applications?

These example applications illustrate the use of various DME Component Libraries features. Each application is also included in the DME Component Libraries installation.

These applications contain notional data and are dual use.

## How do I run these example applications?

This repository does not include DME Component Libraries, which must be obtained separately from [the AGI support site](https://support.agi.com/downloads/?t=3).

You must create an AGI account in order to download DME Component Libraries. After logging in, download either the .NET or Java version.

DME Component Libraries requires a license. Temporary licenses for development and evaluation can be requested from AGI Support by emailing [support@agi.com](support@agi.com).
